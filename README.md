# Portofolio Fathul Khair

Aplikasi portofolio React dengan Vite. Data proyek dan sertifikat berada di `src/portfolioData.js`, dengan aset visual tersimpan di `src/assets/`.

## Menjalankan aplikasi

Jalankan perintah berikut dari folder `portfolio-app`:

```sh
npm install
npm run dev
```

Untuk memeriksa build produksi:

```sh
npm run build
```
